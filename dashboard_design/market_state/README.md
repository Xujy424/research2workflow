# 市场状态面板设计样本

用浏览器打开 `index.html`，无需服务器或联网资源。

## 设计范围

- 只包含市场状态面板；因子检测为独立界面，未在本样本实现。
- 文档指标归并到完整目录。六个时序模块使用代表性指标展示布局，目录中的所有指标并非都已画图。
- 所有序列、股票池差异、截面值、条件 IC 与样本量均为模拟值，不代表真实历史研究。
- 八类状态与因子类型的方向矩阵为机制归纳，不是已验证的因子配置结论。
- 微观结构暂缓；交易容量与退出覆盖等项目需要持仓和交易假设。

## 交互

历史阶段与区间滑块同步所有图。股票池切换修改模拟序列。勾选图例选择维度，切换纵轴可比较原始值或全模拟历史分位。悬停共享观察日期；截面对比可展开。矩阵单元格展开机制与证据，指标目录可以按模块筛选。

## 后续计算口径

1. 原始值按单位分图，历史分位视图需统一回溯窗口，仅使用决策时可得数据；样本当前分位使用全部模拟历史，只用于布局。
2. 风格组合需明确股票池、排序、权重、中性化、调仓与交易滞后。累计收益与窗口滚动收益分别记录。
3. ICIR 需标明未年化或年化；重叠收益标签需在区间推断时处理序列相关性。
4. 宏观、财报、基金持仓使用实际发布日期。ETF 份额变化与价格收益分离，成交占比不可解释为净流入。
5. HHI 与头部成交占比独立计算；机构规模加权持仓用于跨股票比较时需规模归一化。
6. 历史事件标签用于解释，实时状态需可观测的判定规则。阶段沿用用户提供的示意划分，缺口与重叠需在正式数据契约中解决。
7. 盈利与估值贡献分解不等同 Brinson 归因；负盈利与成分变化需独立处理。
8. FactorTest/analyzer.py 统一组织条件有效性结果；信号构造、成本与指增参考既有 Backtest/singleFactor，分层收益参考 UpdateAlpha/backtest.py。
