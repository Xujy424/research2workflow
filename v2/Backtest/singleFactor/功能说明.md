# 单因子回测子项目功能说明

## 1. 项目定位

`v2/Backtest/singleFactor` 用于检验单个因子的经济含义、统计有效性、组合收益和交易容量。项目只接受对齐后的 DataFrame，不读取固定数据路径，使因子计算、数据维护和回测相互解耦。

标准输入均为 `交易日 × 股票`：因子值、股票收益、可交易状态，以及按需提供的行业代码、指数权重和市场权重。

现有数据仓库的 NumPy 数组和 memmap 不需要由调用方手工转换。独立适配函数 `factor_data_from_arrays` 接受矩阵以及 `dates`、`ticks` 两条轴，检查所有矩阵形状后统一包装成 `FactorData`。数组适配集中在 `adapters.py`，不与组合构建或收益计算耦合。完整矩阵调用见 `example_usage.py` 的 `compare_cov_matrix_rebalance`。

## 2. 已支持的因子类型

### 连续值、双边有效因子

使用 `Method.QUANTILE_LONG_SHORT`。买入高分组、卖空低分组，默认保持资金中性，适用于多头和空头均具有稳定经济含义的因子。

### 多头有效、空头无效

使用 `Method.QUANTILE_LONG_ONLY`。只持有高分组，不把低因子值强行解释为负向观点。分析师覆盖度 COV 属于这一类。

### 空头有效、多头无效

使用 `Method.QUANTILE_SHORT_ONLY`。只卖空低分组，高分组保持空仓。执行层可配置融券年化成本 `short_cost_bps_annual`。

### 指数增强与行业对齐

使用 `Method.BENCHMARK_HEDGED` 并传入指数成分权重。组合收益是因子多头减指数收益。

设置 `industry_align=True` 后，先复制基准各行业权重，再在每个行业内部按因子选择股票。因此多头与指数的行业主动权重接近零，主要检验行业内选股能力。300、500、1000的选择由调用方传入相应权重矩阵决定。

### 统一可比的主动权重口径

不同因子统一先生成主动权重 `A`，再记录指数增强组合 `B+A`，回测超额NAV始终使用 `A`。其中 `B` 为指数权重：

- 多头有效：`A = L - B`；
- 空头有效：`A = B - S`；
- 连续双边有效：`A = 0.5 × (L - S)`。

`L` 和 `S` 分别归一化。行业对齐时，两条腿分别复制基准行业预算；某行业没有有效信号时退回该行业基准持仓，因此该行业主动暴露为零。三种类型最后统一缩放到 `active_gross`，使NAV、波动、夏普和换手具有相同主动风险预算下的可比性。

因子输入为原始连续分数时使用 `SignalInput.SCORE`；因子层已经人工选组并归一化时使用 `SignalInput.PREBUILT_WEIGHT`，回测层不会重复排名。结果中的 `active` 是对冲收益权重，`benchmark` 是 `B`，`portfolio`/`total_portfolio` 是 `B+A`，`long_sleeve` 与 `short_sleeve` 保留两侧归一化结果。

收益表同时给出 `benchmark`、`portfolio_gross`、`portfolio_minus_benchmark`、`active_gross` 和扣费后的 `net`。逐日应满足 `portfolio_minus_benchmark = active_gross`，用于审计“指数增强组合减指数”等价于主动权重收益。连续因子若要与单边指数增强因子比较，应使用 `BENCHMARK_HEDGED + ActiveSide.LONG_SHORT`，而不是独立的 `QUANTILE_LONG_SHORT` NAV。

### 事件因子

支持非零触发、变化触发和阈值突破触发，并支持固定持有期、冷却期、重叠事件、全市场截面化和行业内截面化。

`run_event_study` 默认观察事件后1、3、5、10、20日累计收益，输出：

- 每个事件、股票、期限的收益明细；
- 平均收益路径；
- 胜率；
- 事件样本数和独立事件日期数；
- HAC t值和双侧p值。

统计时先按事件日期聚合横截面事件，避免同一天大量股票事件被当成独立样本；随后使用 Newey–West/Bartlett HAC 标准误。默认滞后阶数为 `持有期限 - 1`，用于处理多日收益窗口重叠造成的序列相关。

事件收益支持三种口径：`none` 原始收益、`market` 市场超额收益、`industry` 行业超额收益。

## 3. 显式 Pair Trading

`explicit_pair_weights` 只接受调用方明确给出的 `PairDefinition`，不会在回测样本内自动挖掘配对。每一对必须提供左右资产、对冲比例和经济关系说明。价差信号为正时做多左侧、做空右侧；为负时反向，按固定期限持有。

行业内去均值不等于 pair trading。前者是行业截面中性组合，后者要求两只资产存在可解释且经过样本外验证的稳定关系。

## 4. 执行与未来函数控制

`signal_lag` 明确信号日期与收益日期的间隔；`rebalance_days` 控制调仓频率。组合收益包含换手手续费和空头借券成本。滞后必须根据真实数据可得时间和成交时点设置，不能根据回测结果选择。

调仓日历支持 `daily`、`weekly`、`monthly` 和 `every_n_days`。周度和月度使用每个自然周/月的第一个实际交易日，不用固定5日、20日近似。`compare_rebalance_frequencies` 可以在完全相同的数据与组合参数下同时运行日、周、月三种频率，返回横向绩效表和每种频率的完整回测结果，绩效表包含收益、波动、夏普、最大回撤、胜率和平均换手率。

## 5. 容量模拟

`CapacitySimulator` 与因子有效性检验分离，在因子通过基础检验后使用。当前支持：多资金规模扫描、最小交易手数、成交额参与率、手续费、平方根冲击成本、部分成交、资金曲线和平均成交率。

## 6. 主要输出

`SingleFactorBacktester.run` 返回：日收益、目标权重、绩效汇总、换手率、总敞口、净敞口、RankIC和可选基准权重。

完整调用方法见 `example_usage.py`，其中包含 COV 行业对齐指数增强、空头单边因子、事件研究、容量测试和显式配对五个例子。
